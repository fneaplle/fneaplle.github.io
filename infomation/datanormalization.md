# 데이터 정규화를 하는 이유?

중, 고등학교 정보교과와 인공지능기초과목에서 언급하는 데이터 정규화를 왜 해야하는지 딥러닝 모델 학습과정의 측면에서 살펴보고자한다.
먼저 데이터 정규화란 무엇일까? 그 전에 정규화란 무엇일까?

## 정규화
영어로 Normalization이라 불리는 정규화는 통계에서 처음 접했다. 
중학교때(필자는 92년생이라 중학교 수학에서 정규화를 처음 배웠다.) 통계 과목을 통해 정규화를 처음 배웠을 텐데,
통계에서 정규화는 평균을 0, 표준편차를 1로 만들어서 표준정규분포의 영역에 맞추는 과정이라고 배웠다.

```
x = (데이터-평균)/표준편차
```

위와 같은 과정을 z-score 정규화라고 알고있는데 잘못됬을 수도 있다. 이 외에도 다양한 정규화 방법이 존재한다.(예로 minmax scaling) 예를 통해서 정규화를 통해 얻고자하는 정보가 무엇인지 알아보자.

만약 1000, 1100, 1200, 1300 처럼 100씩증가하는 데이터가 10개 있다고 해보자. 이 데이터에서 1500은 어디 위치에 존재하는가? 중간에 위치한다. 그렇다면 1,2,3,4 처럼 1씩증가하는 데이터가 있다고 가정하면 5는 어디 위치에 존재하는가? 이 또한 중간쯤에 존재한다. 자! 요기서 어디쯤에 위치하는가? 라는 정보를 얻고 싶을때 우리는 정규화를 사용한다. 중간을 0으로 고정시키고, 중간을 기준으로 어느정도 떨어져있냐?를 알고 싶을 때 사용한다고 보면된다.

## 딥러닝에서 정규화?
입력데이터를 보통 -1 ~ 1정도로 정규화한다음 딥러닝 모델의 입력으로 사용한다. 그냥 넣으면 되는데 귀찮게... 왜? 정규화를 한담... 복잡한 수식은 다 제외하고 예시를 하나 간단하게 들어보자. 

우리는 새에 대한 다양한 데이터가 있다고 가정해보자.(진짜 임의로 만든거라 사실과 다름)
|날개길이|부리길이|비행속도|종류|
|---|---|---|---|
|30cm|2cm|50000cm/s|독수리|
|5cm|1cm|5000cm/s|참새|
|30cm|3cm|5000cm/s|비둘기|
|...|...|...|기타등등|

분류하는 딥러닝 모델을 만들고 싶고, 날개길이 부리길이 비행속도와 관련된 데이터가 존재한다. 단위를 cm로 맞추었고, 그러다보니 비행속도와 관련된 데이터의 크기가 다른 데이터의 크기보다 훨씬 크다. 그러면 모델은 다른 데이터보다 비행속도가 매우 중요하다고 생각할 것이고 날개길이나, 부리길이는 신경쓰지 않는다. 하지만 상식적으로 생각해 보았을때, 다른 데이터도 중요하지 않는가? 그렇기 때문에 우리는 실제 데이터를 넣는게 아니라, 정규화된 값을 넣어서 값의 상대적인 위치에 대한 값을 넣는 것이다.(사실 딥러닝 모델을 개발하면 이와 같은 개념이 역전파와도 관련되나 이는 pass)


|날개길이|부리길이|비행속도|종류|
|---|---|---|---|
|4|3|2|독수리|
|-1|-0.4|0.3|참새|
|3.7|0.2|0.4|비둘기|
|...|...|...|기타등등|

위 표는 정규화를 한 후 데이터 값이다.(정규화도 그냥 임의로해서 값이 정확하지 않다 그냥 참고만....) 모든 데이터가 0근처에 위치해 있음을 알 수 있다. 그렇다면 딥러닝 모델은 모든 데이터를 같은 중요도로 해석해 최종 결과에 같은 비율로 반영하게 된다.
